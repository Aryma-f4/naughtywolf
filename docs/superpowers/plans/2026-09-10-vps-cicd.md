# VPS CI/CD Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automatically deploy every pushed `develop` commit to `43.156.147.197`, serve NaughtyWolf at `https://gateofbabylon.space`, and expose the authenticated callback transports.

**Architecture:** GitHub Actions validates the deployment files and invokes a repository-owned script over a dedicated pinned SSH connection. Docker Compose attaches the application to the existing Coolify/Traefik network, persists data in the existing volume, routes HTTPS to port 8080, and publishes raw TCP port 4630.

**Tech Stack:** GitHub Actions, OpenSSH, Bash, Docker Compose, Traefik, Let's Encrypt, Rust/Axum, SQLite

**Spec:** `docs/superpowers/specs/2026-09-10-vps-cicd-design.md`

## Global Constraints

- Deploy only the exact commit SHA supplied by GitHub Actions from branch `develop`.
- Keep application secrets only in VPS `/opt/naughtywolf/.env` with mode 0600.
- Use a dedicated GitHub Actions SSH key and pinned host key.
- Preserve the `naughtywolf-data` volume and never use `down --volumes`.
- Require application container health and public HTTPS health before success.
- Route `gateofbabylon.space` through the existing `coolify` Docker network.

**Interfaces:**
- Consumes: root `docker-compose.yml`, external Docker network `coolify`, `.env`
- Produces: HTTPS router to container port 8080 and host TCP mapping `4630:4630`

- [ ] **Step 1: Record the expected rendered values**

  Require the rendered config to contain `gateofbabylon.space`, external
  network `coolify`, secure cookies, and published port 4630.

- [ ] **Step 2: Verify the current config lacks the VPS routing**

  Run: `docker compose -f docker-compose.yml config | rg 'gateofbabylon.space|published: "4630"'`

  Expected: no matching VPS domain or published callback port.

- [ ] **Step 3: Add the override**

  Add Traefik HTTP redirect and HTTPS router labels with the `letsencrypt`
  resolver, set `traefik.docker.network=coolify`, attach `app` to the external
  `coolify` network, publish `0.0.0.0:4630:4630`, and force
  `NAUGHTYWOLF_COOKIE_SECURE=true`.

- [ ] **Step 4: Render and inspect the merged config**

  Run: `docker compose --env-file deploy/vps/test.env -f docker-compose.yml -f deploy/vps/docker-compose.yml config`

  Expected: exit 0 with the domain, network, labels, and port mapping present.
